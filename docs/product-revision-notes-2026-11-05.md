# 产品改版需求记录 · 2026-11-05

本文件记录用户提出的下一轮改版方向。本次仅记录，不实施界面、功能、登录、数据库或部署变更。

## 1. 网页聚焦核心任务

- 当前网页过于复杂，允许优化、删改不必要的页面、模块、信息和操作。
- 主流程聚焦：输入问题与回答 → 多角色协作核验 → 简洁展示问题或缺口 → 定向补证 → 形成修订建议。
- 动态呈现理想系统中各角色的具体工作与交接，例如规划、独立事实抽取、支持性核验、引用回放与变量绑定、补搜和修订建议。动态内容应让用户看懂本次任务发生了什么。
- 当前模型服务通过 API 接入。产品展示可以呈现理想完成态；尚未实现的能力在对应位置标注“（演示）”，演示过程及结果不作为真实执行记录。
- 不要求保留当前全部导航和研发信息；具体删改项留待实施前梳理。

## 2. 插件改为自动辅助

- 自动识别用户问题和大模型公开回答，减少手动读取、粘贴和逐步点击。
- 回答生成完成后进行检查；无需用户手动拆解整个核验流程。
- 未发现不足或错误时，可保持安静，或推荐一个有价值的后续问题，不必强制展示核验面板。
- 发现错误、缺证或内容不足时，简洁指出具体问题，避免冗长报告占据主界面。
- 给出可直接使用的补充 prompt，帮助原 AI 补充答案或自我纠错；有证据时附上相关依据。
- 用户确认后自动将推荐 prompt 补入原对话。至少覆盖填入对话草稿；是否连同发送由后续交互设计明确，不把本条解释为无需确认即可自动发送。
- 详细证据和步骤作为可展开内容，默认优先展示问题与建议动作。
- 自动识别基于可见问题、回答和公开引用，不将隐藏思维链作为输入来源。

## 3. 插件视觉改版

- 重新设计配色、排版、信息层级与空间分配，解决当前配色和布局不合理的问题。
- 展示重点围绕“发现了什么 → 建议怎么改 → 确认补入对话”。
- 实施时查找并参考用户已下载的 PPT 美化、排版相关 skills，将适合界面的视觉方法用于插件；本轮不安装、不执行相关 skills。

## 4. 网页改用邀请制登录

- 增加登录界面，仅允许受邀用户使用，不提供公开自行注册入口。
- 登录成功后才能进入实际使用界面；以登录会话替代现有访问码交互。
- 登录、会话、邀请及权限需要服务端校验，不能仅靠前端跳转隐藏使用界面。
- 用户已注册 Upstash，允许作为数据库或持久化存储方案；具体服务类型、数据结构和接入方式在实施时确认。
- 邀请创建、发放、失效方式，以及登录凭据形式、历史记录归属等细节尚未确定，本次不擅自选定。

## 5. 网页视觉改版

- 改进整体排版、字体、字号和阅读层级，与简化后的核心任务流程一起设计。
- 网页与插件保持一致的产品视觉语言。
- 实施时同样参考用户已下载的 PPT 美化、排版相关 skills，不拘泥于当前布局。

## 6. 已提供的服务与授权

- **Upstash**：用户已注册，并明确授权后续按项目需要使用和配置。
- **E2B**：用户已注册，并明确授权后续按项目需要使用和配置；本次未指定必须引入的功能，不为使用该服务额外增加产品流程。
- 上述授权作为后续实施上下文保留；本次不访问账号、不创建资源、不修改配置、不产生服务调用。

- 邀请制登录方案，以及旧访问码记录如何迁移或保留。
- 可用于视觉改版的已安装 skills 清单。

## 8. 2026-11-06 实施落盘记录（v0.4.0）

- **邀请制受邀登录与服务端会话 (`cloud_runtime/auth.py`、`app/static/login.html`、`scripts/manage_accounts.py`)**：
  - 新增独立登录页 `/login.html`（含密码眼睛显隐切换按钮），彻底关闭公开自助注册接口（`POST /api/auth/register` 返回 `403 invitation_only`）。
  - 密码采用 PBKDF2-HMAC-SHA256（600,000 次迭代）加盐哈希与常量时间校验；登录成功后签发服务端不透明会话令牌（`HttpOnly; SameSite=Strict` Cookie `ev_session` 及 Bearer 会话令牌），每个受邀账号拥有独立私有记录命名空间（`acct:<user_id>`），同时兼容旧版 SDK/测试的 `Authorization: Bearer <EV_CLOUD_ACCESS_CODE>`。
  - 顶部栏新增受邀用户头像下拉菜单与「个人中心与受邀账号管理」视图，支持管理员在线创建受邀成员、重置临时密码与启停账号，并提供命令行运维脚本 `scripts/manage_accounts.py`。
- **网页聚焦核心任务与 6 角色协同流水线 (`app/static/index.html`、`app/static/app.js`)**：
  - 主导航收敛为「协同总览、答案审查、取证与补搜、审查记录」及「对话插件、帮助与示例、个人中心」，历史诊断与样本整理收拢至折叠研发分组。
  - 新增「多角色协同核验流水线（6 角色分工与交接）」动态看板与交接活动日志（Role 01 对象消歧与范围规划 `含消歧（演示）` → Role 02 盲抽事实提取 → Role 03 独立支持核验 → Role 04 原文回放与变量绑定 → Role 05 缺口定向补搜 → Role 06 修订提示与追问生成），以及一页式高对比度审查结论报告。
- **浏览器插件自动辅助与视觉改版 (`app/extension/page-adapter.js`、`app/static/sidecar.*`、`app/static/plugin.*`)**：
  - `page-adapter.js` 新增流式输出结束与 DOM 稳定检测（`streaming_complete` / `auto_ready`），仅读取可见问题、回答与公开引用，不读取隐藏思考链。
  - 插件与侧栏围绕「发现了什么 → 建议怎么改 → 确认并填入原对话输入框」重构：当所有关系均获支持时展示轻量绿标与延伸追问建议（`verified-clean` 场景）；当发现缺证或实体张冠李戴时置顶呈现修正提示词与一键填入草稿按钮，详细证据与偏移折叠收起。
