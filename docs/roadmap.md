# Roadmap and acceptance gates

这是按依赖排序的工程与实验计划，不是已开始执行的承诺，也未创建可冒充进度的日期。

| 阶段 | 验收条件 | 未通过时 |
|---|---|---|
| 开发诊断复算 | 冻结输入、原始标签、552条旧预测与逐例评分一致；CI离线检查 | 修复归档/代码问题，不改答案过关 |
| API与侧栏接入 | 已有服务配置；三站点实机读入、原文、任务恢复、取消、草稿写回；记录版本 | 保留手动输入，不声称站点已支持 |
| 可靠候选核验器 | 80题联合≥72，正负例各≥36，16个变量题全对、无无效输出、关键负例无误放行 | 分析抽取/支持/匹配/计算；开发题不当独立验证 |
| 3B专用模型 | 正式标签、现有权重、训练预检、保存恢复和可比较基线均具备 | 不启动或不宣称目标训练完成；API版不依赖此阶段 |
| 真实数据评测 | 目标600题人工双标；按来源与用途隔离，明确关系覆盖、OOD、争议与失败计分 | 不给固定错误放行率、显著性或泛化结论 |
| 同预算搜索评测 | 目标300题；无核验、自由重搜、直接裁判、拆分核验输入与预算一致 | 不把多搜的收益归给核验；报告正例召回代价 |
| 成本与产品化 | 同负载记录API用量/延迟或GPU时间；企业访问控制与托管需求另验收 | 不从3B/14B参数比推导节省比例，不声称生产可用 |

未来效果指标：联合正确率、错误放行率FP/(FP+TN)、支持正例召回率、关系覆盖率、正确且证据充分的任务比例。主要结果附分母与适合样本规模的不确定性；真实gold缺失时不自评分闭环。

3B尚未正式训练。目标“600题”“300题”是既有规划规模，尚未形成相应独立标注资产。误放行率≤6%、成本降低60%或提升5pp没有本项目证据作为可靠依据，本次不采用这些精确目标。

未实现的别名消歧、训练轨迹过滤、托管计费和企业私有化部署，先明确输入、输出和测量协议后再安排开发。视频、一页纸、竞品调研与英文材料可作为后续交付，不替代当前代码与结果证据。
