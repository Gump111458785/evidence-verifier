帮助指南与一页式补证示例

了解 Evidence Verifier 的使用流程、判定状态含义，并体验从“发现证据缺口”到“补入新证据通过核验”的完整闭环。

1. 三步完成日常答案核验

  1. 输入或自动捕获：在「答案审查」或浏览器插件中载入用户问题、AI 候选回答与引用原文。
  2. 多角色协同核验：系统自动执行关系规划、盲抽事实提取、支持性复核与原文字符定位。
  3. 定向补搜与一键修订：若存在缺口（Amber）或矛盾（Red），点击「补充检索并复核」，随后将生成的修订提示词复制或一键填入原对话。

2. 结论状态色标说明

支持 · Entailed 所有声明关系均有准确原文引文支持，且跨段落实体绑定一致。
缺失 · Missing 引用原文未提供某跳关系的直接证据（例如把任职记录当作求学经历）。
矛盾 / 失败 · Contradicted 原文与回答结论直接冲突，或实体张冠李戴导致绑定失败。
执行中 · Running 某角色正在执行核验或检索步骤。
示例报告说明 · 使用预设模型判断和教学证据演示完整闭环，原文定位与联合绑定由程序确定性执行，不消耗付费 API 额度。
