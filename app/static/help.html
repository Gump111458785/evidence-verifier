帮助与开源部署

Trisight 三省（Evidence Verifier）是一个基于 MIT 协议开源的外置事实审查项目：不替换主模型，在对话或长文旁侧完成事实拆解、检索核验、遗漏补充与下一问预测。你可以直接使用在线版本，也可以按下方指南自行部署。

项目简介

纠错

提取原回答中的原文事实断言并检索权威来源；只有被原文明确反驳的断言才标红并附更正与引文，未能核实的不伪报为有误。

补充

结合问题与前几轮对话查找对用户重要但回答遗漏的内容；事实类补充附原文出处，回答已充分时返回「无需补充」。

预测

根据问题、回答和上下文预测用户接下来最可能的 1 到 3 个追问，只生成问题不替用户作答，在插件中可一键填入输入框。

仓库目录说明

目录职责与说明
app/本地研究版 HTTP 服务（app/server.py）、静态页面、离线 EV 核验内核与补搜修复模块
app/extension/Chrome MV3 伴随插件脚本与权限配置（打包脚本 app/scripts/build_extension.py 会合并侧栏页面）
cloud_runtime/ & deploy/edgeone/云端审阅接口（/api/assist 分步任务、受邀账号、Redis 预算与 EdgeOne 配置）
api_edition/基于 OpenAI-compatible 接口与远程检索的纯 API 验证版本
sdk/轻量 Python 客户端与公开核验入口（evidence-verifier-client）
scripts/文档链路检查、公开合规检查与 EdgeOne 构建打包脚本

部署教程

01

本地启动研究版

无需第三方依赖或 GPU · 使用 Python 3.11+ 标准库运行

克隆仓库后直接启动本地工作台服务，默认监听 8790 端口，数据写入本机 app/data/workbench.sqlite：

git clone https://github.com/Gump111458785/evidence-verifier.git
cd evidence-verifier
python3 app/server.py --port 8790

启动后在浏览器打开 http://127.0.0.1:8790。注意：本地研究版用于回放诊断与离线核验接口（如 /api/verifications）；云端纠错 / 补充 / 预测三种模式仅在云端运行时开放（本地调用 /api/assist 会返回 501 cloud_only）。

02

安装或自行打包 Chrome 伴随插件

Chrome 116+ · MV3 侧边栏扩展

  1. 直接下载已构建的 evidence-verifier-extension.zip 并解压；如需从本地修改后的源码自行打包，请运行下方命令（不要直接加载 app/extension/，因为侧栏页面文件存放在 app/static/）：
python3 app/scripts/build_extension.py --out dist/trisight-extension.zip
  1. 打开 chrome://extensions，启用右上角开发者模式，点击加载已解压的扩展程序并选择解压目录。
  2. 打开 DeepSeek、ChatGPT、Claude 或 Gemini 对话页后点击扩展图标，使用受邀账号登录即可使用（插件固定连接在线服务 https://evidence-verifier.edgeone.dev）。
03

自行部署云端版本（EdgeOne Pages + Redis + DeepSeek）

包含完整的网页端与 /api/assist 三种模式运行时

若希望独立托管在线审阅服务，需准备 EdgeOne Pages 项目、Upstash Redis REST 存储与 DeepSeek API Key，并在项目的 Production 环境中配置以下 5 项变量：

环境变量用途
EV_DEEPSEEK_API_KEY服务端 DeepSeek API 密钥（模型推理与联网搜索）
EV_CLOUD_ACCESS_CODE不少于 24 字符的服务端访问码（用于脚本 / 管理员鉴权）
EV_REDIS_REST_URLRedis HTTPS REST 入口（存储任务、会话与费用账本）
EV_REDIS_REST_TOKENRedis REST 访问凭据
EV_CLOUD_BUDGET_ID全局试用账本命名空间标识

变量配置完成后，使用白名单打包脚本生成静态资源与 Python 云函数压缩包，并通过 EdgeOne CLI 部署：

python3 scripts/build_edgeone.py --out /tmp/ev-edgeone-build
edgeone makers deploy /tmp/ev-edgeone-build.zip \
  --name evidence-verifier --env production --site global --area overseas \
  --skip-ai-gateway-sync --json
04

运行本地校验与测试

修改代码或二次开发后建议跑一遍离线检查

node --test app/tests/extension/*.test.cjs
python3 -m unittest discover -s app/tests -p 'test_*.py'
python3 -m unittest discover -s api_edition/tests -p 'test_*.py'
python3 scripts/check_doc_links.py
python3 scripts/check_publication.py
